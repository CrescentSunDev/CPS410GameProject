### Git commands
git cheat sheet - https://education.github.com/git-cheat-sheet-education.pdf

DO THIS FIRST IF YOU DONT HAVE THE FILES ON YOUR PC
1. Open git command line
2. use ls to see what folders you can enter
3. use cd \<folder_name\> to get to a spot where you want the repo folder to be placed
4. then use git clone https://github.com/CrescentSunDev/CPS410GameProject.git
5. then cd CPS410GameProject

To upload:
1. git add .
2. git commit -m 'your name here - what changes you made'
3. git push -u main, use git push -u origin main if the first doesn't work

To download (DO THIS FIRST WHEN STARTING UP OBSIDIAN)
1. git pull


To Switch branches:
1. git switch \<branch-name\>

To make a new branch
1. git branch \<branch-name\>



``Warning: Do not include any spaces in the file paths to the source code! This is anything in the SourceCode directory. Use camelCase or hypens (-) instead.``
